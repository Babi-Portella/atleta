# Banner do sistema — imagem escolhida pelo usuário

Arquivo: [banner-atleta-v1.png](../site/assets/banner-atleta-v1.png).
Uso: GitPage, apresentação e entrega acadêmica.
Esta versão foi fornecida pelo usuário em 02/10/2026 e substitui a arte anterior na página e nos pacotes.

O banner apresenta uma **visão conceitual** de monitoramento inteligente de atletas.
Os números exibidos (como 142 bpm, 98% de SpO₂ e 36,7 °C) são elementos gráficos
da imagem; não são registros da placa nem do banco deste projeto.
O M5StickC Plus2 da primeira versão usa o MPU6886 interno para movimento. BPM,
SpO₂, temperatura corporal e GPS exigem módulos, ligações e validações futuras.
O aplicativo ilustrado no banner também não foi implementado; a plataforma atual
é EMQX + MySQL, consultada pelo painel Windows.

A imagem da GitPage é clicável para abrir o arquivo em tamanho original.
